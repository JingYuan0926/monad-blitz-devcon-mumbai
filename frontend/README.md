# Morney — Frontend

Landing page for Morney, built with Next.js (React) and Tailwind CSS. Theme follows the Monad brand kit.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Where things live

- `src/app/page.tsx` — landing page sections (copy follows the root `README.md`)
- `src/components/Navbar.tsx` — nav bar; edit `NAV_LINKS` to change the links
- `src/components/Logo.tsx` — Morney logo mark and wordmark (SVG)
- `src/components/GlyphField.tsx` — animated glyph background
- `src/app/globals.css` — brand colors and theme tokens
